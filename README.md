# DroidNy

Jogo 2D de companheiro virtual: cuide do DroidNy em quatro cômodos (Sala, Cozinha, Quarto e Banheiro), compre comida na mini loja e divirta-se em quatro minigames (Desvio na Pista, Pulos no Céu, Tiro ao Alvo e Jogo da Memória).

## Privacidade
- Funciona 100% offline depois de aberto: não faz requisições externas, não usa fontes da web, analytics, telemetria nem anúncios.
- Os únicos dados guardados ficam no próprio aparelho (moedas, estoque da cozinha e configurações de som, vibração, música e idioma).
- A página declara uma Content-Security-Policy que só permite a própria origem.

## Desenvolvimento
```sh
bun install   # ou npm i
bun run dev
bun run test
bun run build
```
